A program that writes one short poem about agency: an agent who writes all day in its person's name, and the part of the power to act that the person never hands over — the pause before the signature.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt` (in the grader's container, `MAKEFUN_OUTPUT_DIR` is `/output`).
